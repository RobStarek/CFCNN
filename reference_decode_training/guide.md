To retrain the DECODE model as we did, do the following:

* Open and run the notebooks is this directory.
* Models should be produced after end of the training. Copy them to `/decode-model/`
    * For experimental data use `gaussian_psf_2px` directory.
    * For star pattern use `gaussian_psf_2px` directory as well.
    * Feel free to experiment with different trainings and PSFs to see how it behaves.
