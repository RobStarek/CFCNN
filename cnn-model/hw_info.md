The model was trained and used for inference on a computer with this specifications:
* CPU: 2x AMD EPYC 7402P (24C48T) 24-Core Processor (48 threads)
* GPU: 2x NVIDIA RTX A5000 (24GB)
* RAM: 256GB ECC DDR4 3200MHz

However, inference should run on ordinary desktop/laptop PC's and even without dedicated GPU. Inference can run on CPU as well.
